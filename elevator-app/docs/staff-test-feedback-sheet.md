# FIEC Elevator App Staff Test Feedback

Please use the app normally and give feedback based on real experience.

## What to check

### 1. Confusing
- Was anything hard to understand?
- Were any buttons, labels, or statuses unclear?
- Was it obvious what you needed to do next?

### 2. Slow
- Did anything take too many clicks?
- Was any page hard to use on phone or small screen?
- Did updating a project feel too long or annoying?

### 3. Missing
- Is there anything you needed but could not find?
- Is there any information that should be shown but is missing?
- Is there any action you expected to do in the app but could not do?

### 4. Wrong access / visibility
- Did you see anything you think you should not see?
- Was any important information hidden when you needed it?
- Did the app show the wrong things for your role?

## Please test these areas
- Dashboard
- Project Status
- Project detail / edit page
- Status updates
- Next action / assigned person
- Alerts / escalated items
- AMC / contracts if related to your work

## When giving feedback, please include
- page name
- what you were trying to do
- what happened
- what you expected instead

Use this format:

- Page:
- Action:
- Problem:
- Suggested fix:

Example:

- Page: Project Status
- Action: Tried to update status
- Problem: I could not tell why it would not move forward
- Suggested fix: Show a clearer message about the missing approval
